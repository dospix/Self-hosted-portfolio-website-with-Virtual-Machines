 # Self-hosting my Portfolio Website V2 using VMs

This project is meant as a learning tool in order to familiarize myself with virtual machines. I will be using them to self-host my portfolio website using a 3-tier architecture with VirtualBox VMs and Nginx and Gunicorn as servers.

## Architecture

- Web server: Serves a React build of my portfolio website using Nginx
- App server: Uses Gunicorn to run Flask code
- Database server: Uses MySQL to store information (currently just the data used by the task/habit tracker project)

## Tech stack

- VirtualBox
- Nginx
- HTML/CSS(Tailwind)/JavaScript(React)
- Gunicorn
- Python / Flask
- MySQL
- AWS (DynamoDB database used by one of my projects)
